# Contributing

`go-pwr` reads live status from a Go Power! GP-PWM-30-SB solar charge controller over Bluetooth LE. Start with [decision 0001](docs/decisions/0001-go-pwr-design.md) for the design, and [the protocol reference](docs/reference/protocol.md) for how the controller talks. Then read the [development workflow](docs/contributing/development-workflow.md) and the [coding conventions](docs/contributing/coding-conventions.md).
